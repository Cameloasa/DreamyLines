# DreamyLines ✨

## About the Project

DreamyLines is a simple poetry-inspired webpage that presents my favorite things, colors that reflect different moods, and a few poetic thoughts about life.

This project was created as a practice exercise to develop my HTML and CSS skills.

## Technologies Used

- HTML5
- CSS3

## Features

- A header introducing the project
- An ordered list of five favorite things
- An unordered list describing different moods through colors
- A short poetic section
- A footer with a link to information about Mihai Eminescu

## What I Practiced

- Structuring a webpage using semantic HTML elements
- Working with headings, paragraphs, lists, and links
- Using text formatting elements such as `<strong>` and `<i>`
- Connecting an external CSS stylesheet
- Organizing content into sections
- Using inline CSS styles for text alignment

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Explore the DreamyLines webpage.
