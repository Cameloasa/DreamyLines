# DreamyLines ✨

## About the Project

DreamyLines is a poetry-inspired webpage that brings together literature, personal favorites, colors, and moods in an elegant visual experience.

The website features a selection of poets, a poem of the day, an original short poem, a favorite-things list, a color-inspired moods section, and background piano music.

This project was created as a learning exercise to practice semantic HTML, CSS styling, responsive design, accessibility, and basic web testing.

## Technologies Used

- HTML5
- CSS3
- CSS custom properties (variables)
- CSS Flexbox and Grid
- CSS media queries
- HTML5 audio

## Features

- Semantic page structure with a header, navigation, main content, sections, and footer
- Responsive navigation and layouts for different screen sizes
- Original poetry-inspired content
- Featured poem with a link to the complete poem
- Favorite poets with links to biographies and selected poems
- Favorite-things list with individual color accents
- Color and mood section with a coordinated pastel palette
- Background piano music using the native HTML audio player
- Consistent typography, spacing, and colors managed through CSS custom properties
- External links that open in a new tab with appropriate `rel` attributes
- Reduced-motion accessibility support
- Responsive layouts for mobile and desktop screens

## What I Practiced

- Structuring content with semantic HTML elements
- Organizing a webpage into reusable, clearly defined sections
- Working with headings, paragraphs, ordered lists, and unordered lists
- Using text-formatting elements such as `<strong>` and `<i>`
- Creating and styling links to external resources
- Embedding audio with the HTML `<audio>` element
- Building responsive layouts with Flexbox, Grid, and media queries
- Defining and reusing CSS custom properties
- Creating consistent visual styles without unnecessary CSS duplication
- Improving accessibility through descriptive content, keyboard-friendly navigation, and reduced-motion preferences
- Testing the website across different screen sizes

## Testing and Validation

The following tools were used to inspect and test the project:

- **Chrome DevTools** — inspecting the page, checking layout behavior, and debugging HTML/CSS
- **Lighthouse** — auditing performance, accessibility, best practices, and SEO
- **W3C Nu HTML Checker** — validating HTML markup: [validator.w3.org/nu](https://validator.w3.org/nu/)

The website was checked on desktop and mobile screen sizes. Lighthouse scores reached 100 in the tested categories after optimization.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Explore the DreamyLines webpage and its poetry-inspired sections.
